# RT3 — what to ADD (the "try this" seat). Ranked. Nothing here is a bug report.

**1. ⭐⭐ THE PROOF-CARRYING LOADER — put the synthesized region in the silicon.** The region is a conjunction of *linear inequalities over table fields* (`19U > G0+8G & G0+9G > 19U & G0 > U`). Membership is integer multiply-accumulate and compare, so a coefficient ROM **generated from Imitator's own output** plus a one-term-per-cycle evaluator makes the hardware's accept-set *literally* the proved region: a table outside it cannot be armed, and the reject code names **which conjunct** failed ("your start bit is shorter than the receiver's half-period") — a diagnostic no datasheet can give. Only possible with a region over the fields an operator reprograms; no other team has one.
*Cost* ~150–250 cells (3–6 conjuncts, 16-bit fields, serial MAC), **zero new descriptor fields — it wraps the load path, it does not touch the frozen six.** *Experiment (≈2 days, model only)*: `admissible(table) -> (bool, violated_conjunct)` parsing `table_guard.res`; sweep integer `(G0,G)` over a box and diff its verdict against interpreter+sigrok ground truth. *Falsifier — and it WILL fire*: Finding 3. Today's region is a **framing** region (`G∈[2,488]`) and will accept tables sigrok misdecodes. **So the deliverable is the checker plus a region synthesized over a 10-sample, byte-judging monitor**; `probe_startbit_tradeoff` already measured that true answer as `[386,488]`, which is the oracle the gate asserts against. Shipping the *current* polytope in silicon would ship a 5×-overstated envelope — that is the one way this idea goes badly.

**2. ⭐⭐ MONITOR-AS-A-TABLE — one interpreter, two roles, and it retires the defective receiver.** The descriptor as frozen can **already** express a bus monitor: edge-wait is `E(g=1, in_pin=rx, in_pol=1, next_a=self, next_b=advance)` (self-loop while high, advance on the falling edge — 1-clock resolution = 0.23% of a 434-cycle bit), and "reject" is a reserved `pc`. So a *monitor table* on the unchanged machine is a line-rate hardware conformance checker, and the Exec/Mon pair in `table_guard.imi` becomes **two instances of the same machine** — a self-certifying table *pair*, not a machine plus a bespoke judge.
*Cost* in silicon: a second `(pc,clock)` pair ≈40–60 cells, a reject latch, table-RAM time-multiplexing (prereg says 11.7% duty for three lanes, so there is room). *Experiment (≈1 day, free)*: write the UART monitor as a table, run it against TA-02's own emitter in `interp.py`, and check it reaches the reserved `pc` **exactly at the 458 edge** that Imitator and TChecker agree on. *Why this is the Monday task*: it executes forward-plan option (c) **by mechanism instead of by documentation** — the phase-checking monitor that replaces `UartReceiver` is a table on the proved machine, so Findings 1 and 2 are retired by deletion, and the 10-sample monitor idea 1 needs is the same artefact. *Falsifier*: the table monitor cannot reproduce 458 (then the descriptor cannot express the property the formal models check, which is a far more interesting finding than the off-by-one).

**3. ⭐ MEASURE A THIRD PARTY'S TOLERANCE — the chip as a conformance instrument.** Everyone will do auto-baud (and edge timestamping is already prereg'd, so claim no novelty there). The forward move: because our own transmit is *proved* in-band and loader-enforced, any failure can be **attributed to the peer** — so sweep `G` across the admissible region and binary-search the peer's acceptance edge. Output: a measured tolerance band for somebody else's receiver, against a yardstick that is a theorem. A normal emulator can measure *that it failed*; it cannot attribute.
*Cost* ≈0 on-chip if the host drives the sweep over the load interface (chip needs only ideas 1+2). *Experiment (one afternoon, free)*: make **sigrok the peer** — sweep `G`, find sigrok's own acceptance edge, compare to `[386,488]`. That is a foreign receiver's band measured by our device, and it is a **7th independence item**. *Falsifier*: sigrok's edge lands outside the predicted band in a way the resampler explains (it resamples at true baud — TA-02 already logged that a foreign authority bounds what it can resolve), in which case this needs a real UART at the FPGA rung before it means anything.

**4. SPEC → TABLE COMPILER, and the expressiveness theorem that comes with it.** Make the chip a compile target: a single-clock deterministic timed automaton in, `(table, certificate)` out, where the certificate is Imitator's region on the *same source* and the loader (idea 1) checks it. Spec → table → proved envelope → on-chip refusal, one pipeline. *The genuinely new artefact is the negative half*: characterize **which single-clock TAs are table-expressible.** *Prediction against forward-plan assumption 5 ("the minimal descriptor is stable")*: a branching entry samples **only** at `x+1 == g`, so "wait for an edge **but time out**" — whichever comes first — is **not expressible**. Poll forever, or sample once; not both. I²C clock stretching, SPI CS deglitch and every robust monitor need exactly that race. Fix is one **mode bit** reinterpreting a branching entry's `g` as a *deadline* rather than a *duration* (`next_b` = expiry arm), not a seventh field — so flag it as the **predicted third descriptor extension**, alongside the known FIFO and tri-state. *Experiment (paper, 1 day)*: try to write an I²C-with-stretching monitor table; the attempt either succeeds or names the extension precisely. *Cost*: ~1 bit per entry in the table RAM plus one comparator; the compiler is host software.

**5. MAKE ONE TILE THE HEADLINE, WITH A NUMBER.** The proof does not grow with the protocol (zone states flat at **37** across a 96× range of `T`), so the honest pitch is "per-protocol area → 0, and the certificate is cheaper than one extra protocol." *The line worth earning*: **the certificate ROM is smaller than the table RAM it guards.* Experiment (half a day)*: yosys the idea-1 checker alone and count cells against a 64-entry table RAM. If true it is a killer sentence; if false it kills idea 1 on cost, cheaply. Free polish: **generate the datasheet's timing section from Imitator's output** and gate that `info.md` matches the region — judges read the datasheet, and a machine-derived one is the moat made visible. ⚠️ *Flag*: one tile is self-imposed — prereg discrepancy 1 records Jane Street allowing **6×4 tiles**, and ideas 1+2 together are a defensible reason to spend a second tile rather than lose the loader.

**6. LONG SHOTS, flagged as such.** (a) **Witness-on-reject**: when the loader refuses, drive a *precomputed* table that exhibits the violated conjunct on a scope — "the chip shows you why your config was refused." Cheap (canned tables), pure demo value, generating the witness on-chip is not affordable. (b) **Signed envelope**: ⛔ **blows the tile budget** — any real hash/signature core is >1K cells. The affordable version is a 16-bit **CRC over (table ‖ polytope-ROM id)** readable on a status pin, ~60 cells, so a field operator can confirm the loaded table is the one that was proved offline. Call it attestation-shaped, never "signed". (c) **Table-equivalence as the licence for the FIFO extension**: prove the 31-entry baked-payload table and a FIFO-fed table are observationally equivalent *over the region*, so the extension is a refinement that preserves the proof instead of re-triggering it. Strongest of the three, but any team with a model checker could attempt it — lowest moat, so lowest rank.
